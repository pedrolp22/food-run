Initial Public Release of Food Run, a C++20 lane runner with an animated cat,
food collectibles, a day/night cycle, graphics settings and a PSX-inspired mode.

Download the ZIP for your platform, extract the entire folder, and run `foodrun.exe`
on Windows or `./foodrun` on Linux. The game includes its assets, SDL and compiler
runtime support. An OpenGL 3.3 graphics driver is required. Official Linux builds
target x86_64 Ubuntu 22.04 / glibc 2.35 or newer compatible systems.

The `-source.zip` archive contains the matching source and build instructions.
SHA-256 checksum files accompany every ZIP.

a noncommercial road barrier model. See the included third-party notices.
